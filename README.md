# A “Frontier” OSR Campaign Setting
Based on the idea of the False Hydra from [Goblin Punch](https://goblinpunch.blogspot.com/2014/09/false-hydra.html) (big spoilers!). The campaign begins twenty years after the Hydra depopulated an entire valley, which was sealed off after the survivors fled the region.

With the seal now lifted, everything is up for grabs:
Land, natural resources, the treasures left behind in the panic.
While the thread of the Hydra's return lingers in the background,
the initial focus are the immediate dangers of a land untouched by humans for decades.

The setting fuses elements of a post-apocalyptic, dangerous ~~waste~~ “lush” land with those of a Wild West frontier setting.

## Dir Structure
### `public`
contains the zine-like handout for the players. The makefile produces an A5 `screen` version and a `print` version consisting of A4 spreads intended for double-sided printing and binding.

### `secret`
contains random tables, dungeon maps and the like for the referee (game master).
